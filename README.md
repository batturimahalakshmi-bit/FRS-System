# Face Recognition Attendance System

A Python-based Face Recognition Attendance System that automatically identifies registered students and records their attendance.

## Features

- User Login System
- Face Registration
- Face Detection
- Face Recognition
- Automatic Attendance Marking
- Duplicate Attendance Prevention
- Attendance Dashboard
- Attendance Records with Date and Time
- Unknown Face Detection
- CSV-based Attendance Storage

## Technologies Used

- Python
- OpenCV
- OpenCV Contrib
- NumPy
- Tkinter
- CSV
